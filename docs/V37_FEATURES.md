# v37 — أدوات التطبيق

تمت إضافة واجهات عملية للبحث والقاموس، TTS، SRS، المدرس المتكيف، الاختبارات، تصحيح الكتابة الأساسي، المحادثة والمواقف، الإحصائيات، والعمل دون اتصال.

الميزات التي تحتاج خدمات خارجية بقيت معلّمة بوضوح كغير مفعلة: Cloud Sync، Speech-to-Text، AI السحابي، وAndroid QA/APK حتى يتم تنفيذها واختبارها فعليًا.
