# V51 — Vocabulary and Verb Quality Update

- Removed legacy duplicate German headwords by normalizing article-insensitive forms; retained the first existing record for each headword.
- Added 500 new, non-duplicate German headwords after cleanup, plus 29 repair replacements for malformed legacy records.
- Final vocabulary count: 6,813 unique normalized German headwords after cleanup and repair replacements.
- New vocabulary is separated into topical categories and includes Arabic meaning, German example, Arabic example, and noun article/plural where applicable.
- Rebuilt the verb conjugation dataset into 11 learner-friendly sections with 167 verbs.
- Each verb has six Präsens forms (ich, du, er/sie/es, wir, ihr, sie/Sie), one German example per form, and Arabic translation for every example.
- Corrected several previously malformed regular/separable/irregular present-tense forms, including separable verbs and `sich bewerben`.
- No APK/AAB build is claimed in this update; this remains a source-project release.
