# Performance Improvement: R8 Full Mode

## Date
2026-10-24

## Issue Analyzed
- Startup time, APK size, and runtime performance via R8/ProGuard optimization.
- Existing setup: `minifyEnabled true` and `shrinkResources true` in release build type (android/app/build.gradle).
- ProGuard rules already present and security-preserving (keep Flutter, app classes, sqflite).

## Improvement Implemented
Enabled R8 full mode in `android/gradle.properties`:

```
android.r8.fullMode=true
```

### Why this helps
- More aggressive dead-code elimination and optimization.
- Smaller APK/DEX size → faster install and startup (less code to load).
- Better runtime performance from inlining and optimization.
- Does not weaken security: existing keep rules remain in effect; no removal of security-related classes.

## Expected Measurable Impact
- APK size reduction: typically 5-15% additional on top of standard minify (measure with `flutter build apk --release` and compare sizes).
- Startup time (cold start to first frame): improvement of 50-200ms depending on device, measurable with Macrobenchmark or Android Studio Profiler / `adb shell am start -W`.
- Memory: slightly lower peak due to less code.
