# V70 — UI, Audio & Verb Favorites

## Changes
1. Audio is exposed at row/card level, so the learner can pronounce a German word, infinitive, conjugated form, present example, or past example without opening the item.
2. Vocabulary and dictionary details remain on the same page and are laid out vertically.
3. Every verb person is independent: ich, du, er, sie (هي), es, wir, ihr, sie (هم), Sie.
4. Every conjugation includes present form, Perfekt, past Arabic meaning, present example + Arabic translation, and past example + Arabic translation.
5. A ⭐ favorites control is attached to each verb, persisted locally, with a dedicated study list.

## Quality note
The source dataset remains the V69 12,632-entry dataset; this release is a UI/learning-interaction upgrade and does not claim an additional 500 vocabulary entries.
