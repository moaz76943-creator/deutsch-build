# v35 — A1 Learning Core

v35 يركز على تحويل كل عنصر A1 إلى وحدة تعلم متعددة الأدلة بدل بطاقة مفردة.

## Proof of Learning
Recognize → Understand → Listen → Produce → Transfer → Retain

## مطبق
- جلسة تكيفية تختار المهارة الأضعف أو المراجعة.
- جلسة عنصر واحد تمر عبر مراحل الإتقان.
- زمن الإجابة والدقة والتلميح تدخل في سجل المحاولة.
- أمثلة على collocations والقواعد المرتبطة بالكلمة.
- Germany Reality Layer: قطار، مواصلات، متجر، طبيب، عمل، سكن، هاتف ورسائل.
- تقرير أسبوعي مبني على آخر 7 أيام.
- Privacy/Offline/Quality Center منفصلة عن تجربة الطالب.
- عدم استخدام أرقام mastery وهمية.
