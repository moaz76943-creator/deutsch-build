# V377 — Incremental Compiler & Dependency-Aware Verification

## Scope

V377 continues the development-acceleration track after V376. It adds two narrowly scoped capabilities:

1. **Chunk-level incremental content compilation** — generated Dart chunks are rendered deterministically, but existing chunks are rewritten only when their generated bytes actually change. Aggregator files are also preserved when their content is unchanged, and stale chunks are removed when the source shrinks.
2. **Dependency-aware impact analysis** — `tool/change_impact.py` builds a reverse Dart import/export graph and follows transitive dependents. Fast verification and cache fingerprints include the proven affected dependency scope, so a change in a shared contract cannot incorrectly reuse a cache entry whose dependent source changed.

The release path remains full and fail-closed. No security, entitlement, learner-state, or persistence-security behavior was intentionally changed.

## Verification contract

- New regression tests cover selective chunk rewrites and dependency propagation.
- Existing V374/V376 behavior tests remain in the suite.
- Fast verification continues to report unaffected checks explicitly as `SKIPPED — unaffected`.
- Release verification remains separate from Flutter build verification.
- Flutter/Android build success is **not claimed** when the Flutter SDK is unavailable.
