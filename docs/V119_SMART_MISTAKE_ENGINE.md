# V119 — Smart Mistake Engine

V119 adds diagnostic intelligence to the existing mistake and repair pipeline.

- Tracks overall failure rate and recent 14-day failure rate per item.
- Raises priority for actively recurring mistakes.
- Produces category-aware Arabic diagnostic guidance.
- Learning plans expose the diagnosis instead of only a generic repeated-error label.
- Repair drills adapt their recognition/correction prompts for Artikel and grammar errors while preserving the existing three-step flow.
- Existing content IDs and learner persistence formats remain compatible.
