# V107 — Adaptive Session Integration

## الهدف
ربط جلسة التعلم الأساسية فعليًا بخطة `LearningEngine` بدل تجاوزها واستخدام قائمة المراجعة الخام.

## التغييرات
- `CoreSession` يبني خطة من `LearningEngine.buildPlan` بواقع 6 عناصر.
- يحتفظ بالعناصر المختارة والخطة نفسها طوال الجلسة، فلا تتغير العناصر بعد تسجيل كل إجابة.
- يختار نمط الجلسة من مهارة العنصر أو من سبب الخطة (`review`/`repair`/`consolidate`).
- يبقى مسار fallback موجودًا إذا لم تنتج الخطة عناصر صالحة.
- لا تغيير في IDs أو حالة التقدم المخزنة.

## الاختبارات
- اختبار تكامل ثابت يمنع عودة تجاوز `LearningEngine`.
- اختبار يضمن ثبات الخطة طوال الجلسة.
