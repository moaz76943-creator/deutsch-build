# V133 — Weakness & Accessibility Hardening

## الهدف
ركز هذا الإصدار على نقاط الضعف بدل توسيع نطاق الميزات، مع إعطاء أولوية لـ Accessibility وتقليل مخاطر null assertions في مسارات الواجهة والخدمات.

## ما تم إصلاحه
- إزالة null assertions عالية الخطورة من درجات المهارات في لوحة الصفحة الرئيسية.
- إزالة null assertions من خرائط الأسئلة/التصنيفات والتجميعات في الواجهات.
- جعل تجميع مستويات المحتوى يتحمل lookup غير موجود بدل فرض قيمة غير null.
- جعل حساب متوسطات المهارات في Mastery Dashboard يستخدم fallback آمن.
- إضافة Semantics إلى أشرطة المهارات لعرض اسم المهارة ونسبة الإتقان لقارئات الشاشة.
- إضافة tooltips واضحة لأزرار الصوت icon-only في المسارات التي تم لمسها.
- تحديث رقم الإصدار إلى `1.78.0+88`.

## ما يزال غير مثبت
- لم يتم تشغيل Flutter/Android runtime لأن Flutter SDK غير متاح في بيئة التنفيذ الحالية.
- لذلك لا ندّعي Android crash-free أو نجاح Accessibility على قارئ شاشة حقيقي.
- يجب عند توفر Emulator/جهاز Android إجراء اختبار فعلي للنصوص الكبيرة، TalkBack، touch targets، focus order، ودورات lifecycle.

## الأولوية التالية
- استكمال Accessibility على كامل الواجهة وليس فقط أشرطة المهارات.
- تقسيم `lib/ui_v35/app.dart` تدريجيًا بعد تغطية السلوك باختبارات.
- تحسين جودة المحتوى المرشحة للمراجعة البشرية، خصوصًا near-duplicates، بدون حذف آلي.
- قياس الأداء قبل أي إعادة هيكلة كبيرة لملفات المحتوى.
