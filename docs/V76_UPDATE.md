# V76 — Free + Premium plans

## Pricing
- Monthly: $5/month
- 3 months: $10 every 3 months
- Yearly: $25/year

## Implemented
- Added a visible subscription entry point on the home screen.
- Added a dedicated plans/paywall page.
- Added clear free-vs-Premium feature separation.
- Premium-gated entry points for Writing Coach and Conversation.
- Added local entitlement service as a safe architecture layer.
- Explicitly does **not** fake real payment; Google Play Billing/App Store integration and product IDs are required before charging users.
- Existing vocabulary, verb conjugation, TTS, categories, favorites, and learning data are preserved.

## Product recommendations applied
1. Keep useful basics free to demonstrate value.
2. Put personalization, smart review, advanced tests, deeper analytics, and ad-free experience in Premium.
3. Highlight the 3-month plan as best value and yearly as the most economical long-term option.
4. Explain locked features instead of showing a generic paywall.
