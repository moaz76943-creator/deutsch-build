# Deutsch بالعربي 🇩🇪🇦🇪

تطبيق تعلم اللغة الألمانية المصمم خصيصاً للمستخدم العربي، بطابع **فردي بالكامل (Offline-First)** ومعمارية برمجية نظيفة تركز على الخصوصية، السرعة، والأداء العالي.

## 🚀 الميزات الأساسية للمنصة
- **معمارية نظيفة ومستودع بيانات (Repository Pattern):** فصل كامل بين طبقة الواجهات ومنطق التخزين المحلي الآمن.
- **التخزين الدائم (Local Persistence):** حفظ المفردات والتقدم عبر `shared_preferences` ومعالجة الأخطاء الآمنة (Safe Async Wrapper).
- **لوحة التحكم المركزية (Unified Dashboard):** إمكانية الوصول السريع لكل الأدوات والأقسام.
- **أدوات تعلم ذاتية متقدمة:** مدرب النطق الفردي، مراجعة البطاقات الذكية (SRS)، مفكرة الكلمات الحية، ومدرب التهجئة الإملائية.

## 🛠️ التقنيات المستخدمة
- **Framework:** Flutter & Dart
- **State & Architecture:** Clean Architecture Principles, Repository Pattern
- **Local Storage:** SharedPreferences & JSON
- **CI/CD:** GitHub Actions Automation
